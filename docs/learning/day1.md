# День 1: что студент должен понять

## Web-приложение

Пользователь открывает страницу в браузере. Браузер отправляет HTTP-запрос на сервер. Django принимает запрос, выполняет код во view, читает или изменяет данные в базе и возвращает HTML-страницу.

## Backend

Backend отвечает за бизнес-логику: заявки, оборудование, роли, отчеты, рекомендации решений.

## Frontend

Frontend в проекте сделан через Django Templates. Это HTML-шаблоны, куда Django подставляет данные из базы.

## База данных

PostgreSQL хранит пользователей, оборудование, заявки, комментарии и решения. Связь между заявкой и оборудованием реализована через внешний ключ.
