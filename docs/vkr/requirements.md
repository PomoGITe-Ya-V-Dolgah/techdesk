# Черновик технического задания

## Назначение разработки

Web-приложение предназначено для автоматизации учета и обработки заявок отдела технического обслуживания предприятия.

## Функциональные требования

- авторизация пользователей;
- разграничение прав по ролям;
- ведение справочника оборудования;
- формирование QR-паспорта оборудования;
- создание и обработка заявок;
- назначение исполнителей;
- изменение статусов заявки;
- фиксация итогового решения;
- просмотр истории неисправностей по оборудованию;
- показ похожих ранее решенных заявок;
- формирование отчетов.

## Требования к надежности

- обязательная авторизация;
- ограничение действий по ролям;
- валидация обязательных полей;
- сохранение истории комментариев и решений.

## Требования к техническим средствам

- ОС: Windows, Linux или macOS;
- Python 3.12 или выше;
- PostgreSQL 16 для целевой эксплуатации;
- браузер Chrome, Edge, Firefox или Safari.
