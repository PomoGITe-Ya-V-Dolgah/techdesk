# Принятые решения

## Django вместо FastAPI + React

Выбран Django, потому что за 2 недели важнее получить завершенный и понятный продукт. Django дает авторизацию, ORM, миграции, формы, шаблоны и admin-панель без лишней инфраструктуры.

## PostgreSQL как целевая БД

PostgreSQL соответствует предпочтительному стеку и хорошо подходит для ВКР с инфологической моделью. SQLite оставлен как fallback для быстрого запуска без Docker.

## Рекомендации без LLM

Для ВКР выбран прозрачный алгоритм: совпадение оборудования, категории и ключевых слов. Его легко протестировать, объяснить и защитить.

## QR-паспорт оборудования

QR-код ведет на создание заявки с выбранным оборудованием. Это практичная фишка: пользователь не ищет оборудование вручную, а история заявок автоматически привязывается к объекту.
