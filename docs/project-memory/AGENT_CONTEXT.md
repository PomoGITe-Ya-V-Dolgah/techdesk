# Контекст проекта для AI-агента

## Тема

«Проектирование и разработка web-приложения для учета и обработки заявок отдела технического обслуживания предприятия».

## Цель

Разработать понятный студенту, готовый к демонстрации MVP Service Desk, который показывает не только учет заявок, но и накопление истории неисправностей по оборудованию.

## Новизна

Система формирует QR-паспорт оборудования и использует историю закрытых заявок как базу опыта технического отдела. При создании или просмотре заявки приложение показывает похожие ранее решенные случаи, чтобы инженер быстрее нашел рабочее решение.

## Стек

- Python, Django
- PostgreSQL как целевая БД
- SQLite допустим для быстрого локального тестирования
- Django Templates + Bootstrap
- Docker Compose для PostgreSQL

## Главный принцип

Код должен быть объясним студентом на защите. Сложные LLM-механики внутрь продукта не добавлять; рекомендации решений реализуются простым и прозрачным алгоритмом.
